# Commands

Generated by `npm run docs:commands`. Do not edit by hand.

Every command works as a slash command and with the server's prefix (default `-`).

| ----------------- | ------------------------------------ | ------------- |
| `/help [command]` | List commands or show how to use one |               |
| `/about`          | About leurs                          | `-info`       |
